## Extracted principles for THE CONVERGENCE

1. **Medium = proof** (Simon): the journey itself must *behave* like Majid's
   systems — governed, evidence-linked, fail-closed interactions; not just
   describe them.
2. **Progression is felt** (Leonardi): the visitor must experience increasing
   complexity (graph density, gates, loops), not read about it.
3. **Editorial precision + interactive depth** (Comeau): short high-signal
   copy; depth lives in drawers, ledgers, hover/tap states.
4. **Signal first, depth on demand** (OS-folio): a busy recruiter gets the
   thesis in 60–90s; an engineer can spend 20 minutes in ledgers.
5. **Sequence over curation** (van Schneider / our constraint): the one
   narrative spine is depth-of-layer; everything hangs on that order.
6. **Running systems > claims** (Lee): every scene links to a real public
   artifact (repo, live site, deployed route).
7. **No template feel**: none of the eight uses a timeline-of-logos; neither
   will we (explicit ban).
8. **Motion explains, never decorates**: every animation answers "what
   changed at this stage?" (scene-specific motion semantics, like the hero
   simulator's WAITING/HANDOFF semantics).
