## Display policy (implemented in src/components/books/BookCover.tsx)

1. Cover URL: `https://covers.openlibrary.org/b/isbn/{isbn13}-L.jpg?default=false` (hotlink; bytes never stored locally).
2. Credit link: `https://openlibrary.org/isbn/{isbn13}` under every cover.
3. ISBNs measured as coverless (receipts) skip the network request entirely — the text card renders directly (no 404 console noise; after-report shows 0 console errors).
4. On runtime failure of a verified cover: onError → same designed text card (never generated art).

## Verification method (deterministic, re-runnable)

```
node scripts/sb-verify-books.mjs
```
per ISBN: Open Library edition record (title/publisher/date cross-check) → cover HTTP
status + MIME + byte size + JPEG SOF dimensions → Google Books volume cross-check
(rate-limited during this run; receipts record the 429s honestly). Output:
`content/knowledge/cover-receipts.json` (committed as the receipt of record).
